# نگاه مدیا | Negah Media

وب‌سایت فارسی و راست‌به‌چپ آژانس «کیان فناوران نگاه»، با PHP، CSS و JavaScript ساده؛ بدون دیتابیس، فریم‌ورک یا وابستگی زمان اجرا به Node.js.

## امکانات

- طراحی روشن و واکنش‌گرا با پالت سبز، سرمه‌ای، زیتونی و کرم؛ طراحی آژانسی با الهام از تمرکز تصویری Apple، سلسله‌مراتب محتوایی Stripe و اولویت آثار در Pentagram
- یک معرفی تصویری ثابت با فرم اختصاصی «نگاه»، آثار در اولویت، خدمات آکاردئونی و بخش درباره با کنتراست سبز تیره؛ بدون اسلایدر یا بنرهای تکراری
- جزئیات پروژه همراه پیش‌نمایش تصویری در پنجره دسترس‌پذیر، گالری افقی آثار در موبایل با دکمه‌های قبلی/بعدی و فرم درخواست همکاری
- هدر شناور شیشه‌ای، مشخص‌شدن بخش فعال منو، بستن منوی موبایل با Escape یا کلیک بیرون
- فرم با تبدیل ارقام فارسی/عربی، شمارنده متن و وضعیت ارسال؛ بدون وابستگی عملکرد اصلی فرم به JavaScript
- پنل مدیریت در `/admin.php`، با نام کاربری `Mohusyn` و رمز اولیه اعلام‌شده در درخواست مالک
- ویرایش متن‌های اصلی، مشخصات برند، شماره تماس و خدمات
- افزودن، ویرایش و حذف پروژه‌ها، بارگذاری تصویر JPG/PNG/WebP
- مشاهده درخواست‌های فرم، علامت‌گذاری خوانده‌شده و حذف
- بارگذاری فونت WOFF2/WOFF/TTF و بازگشت به وزیرمتن
- تغییر تصویر اصلی از پنل، با امکان بازگشت به تصویر پیش‌فرض
- تغییر رمز عبور؛ رمز فقط به صورت هش bcrypt نگهداری می‌شود
- محافظت CSRF، کوکی HttpOnly و SameSite، محدودسازی تلاش ورود و اعتبارسنجی فایل‌ها
- ذخیره JSON همراه با قفل فایل برای جلوگیری از تداخل نوشتن

آثار اولیه **مفهومی** هستند، نه ادعای انجام پروژه برای مشتری واقعی. آن‌ها را از پنل با آثار واقعی جایگزین کنید. تنها راه‌های ارتباطی عمومی سایت شماره تماس و فرم هستند.

## نصب روی IIS

۱. PHP نسخه **8.1 یا جدیدتر**، ترجیحاً نسخه پشتیبانی‌شده 8.4 یا 8.5، و قابلیت **CGI/FastCGI** را روی Windows Server نصب کنید. درخواست‌های `*.php` باید به `php-cgi.exe` نگاشت شوند. PHP باید قابلیت‌های استاندارد session، JSON، password hashing و دریافت فایل را داشته باشد.

۲. ریشه همین پروژه را به عنوان ریشه وب‌سایت IIS تنظیم کنید؛ سایت برای مسیر ریشه دامنه طراحی شده است، نه زیرپوشه. فایل `web.config` باید اعمال شود. نیازی به URL Rewrite نیست.

۳. به هویت Application Pool (برای مثال `IIS AppPool\NegahMedia`) مجوز **Modify** فقط روی `data` و `uploads` بدهید. روی بقیه پروژه مجوز خواندن کافی است. دسترسی نوشتن عمومی (`Everyone`) ندهید. پوشه session PHP نیز باید قابل نوشتن باشد.

۴. در `php.ini`:

```ini
file_uploads = On
upload_max_filesize = 5M
post_max_size = 6M
display_errors = Off
log_errors = On
session.use_strict_mode = 1
```

۵. MIME typeهای `.woff` → `font/woff`، `.woff2` → `font/woff2` و `.webp` → `image/webp` را اگر در IIS موجود نیستند اضافه کنید.

۶. HTTPS را فعال کنید، وارد `/admin.php` شوید و **رمز اولیه را تغییر دهید**. پیش از عمومی کردن سایت مطمئن شوید `/data/auth.json`، `/data/site.json`، `/.git/HEAD` و `/core.php` قابل دریافت نیستند (پاسخ 404). محافظت این مسیرها در `web.config` تعریف شده است. فایل `uploads/web.config` اجرای اسکریپت در پوشه آپلود را غیرفعال می‌کند.

۷. محتوا و آثار را تکمیل کنید و ارسال یک فرم و دریافت آن در پنل را روی سرور نهایی آزمایش کنید.

**توجه:** اجرای PHP و جریان‌های کاربردی در محیط لینوکس آزمایش شده‌اند؛ IIS در این محیط موجود نیست و تنظیمات FastCGI، مجوزها و web.config باید روی سرور ویندوز نهایی بررسی شوند. اگر از Apache یا Nginx استفاده می‌کنید، باید قوانین منع دسترسی به data و جلوگیری از اجرای فایل‌های آپلود را جداگانه تنظیم کنید؛ web.config مخصوص IIS است.

## اجرای محلی با PHP

```sh
php -S 0.0.0.0:8080 router.php
```

سایت: `http://localhost:8080/` — پنل: `http://localhost:8080/admin.php`

`router.php` فقط برای پیش‌نمایش محلی و محافظت مسیرهای خصوصی در وب‌سرور توسعه است. وب‌سرور توسعه را برای سرویس عمومی تولید استفاده نکنید.

در محیط Arena که PHP بومی نصب نبود، پیش‌نمایش از مفسر PHP WebAssembly در بسته `@php-wasm/cli` استفاده می‌کند. این ابزار برای نصب IIS لازم نیست.

## داده و پشتیبان‌گیری

- `data/site.json`: محتوای سایت و آدرس فایل‌های آثار و فونت
- `data/auth.json`: نام کاربری و هش رمز
- `data/messages.json`: درخواست‌ها (در اولین ارسال ایجاد می‌شود، خارج از Git)
- `data/attempts.json`: شمارنده تلاش ورود (خارج از Git)
- `uploads`: فایل‌های بارگذاری‌شده (خارج از Git)

از `data` و `uploads` با هم و در یک محل خصوصی نسخه پشتیبان بگیرید. هنگام انتشار نسخه جدید، داده‌های موجود سرور را با فایل‌های نمونه پروژه بازنویسی نکنید. حذف یک پروژه یا تعویض فونت، فایل قبلی را خودکار از uploads پاک نمی‌کند؛ برای حفظ امکان بازیابی، پاک‌سازی فایل‌های بدون استفاده را پس از پشتیبان‌گیری انجام دهید.

این سامانه فرم‌ها را در پنل نگه می‌دارد؛ هیچ ایمیل یا پیامک خودکاری ارسال نمی‌کند.

## بررسی‌های انجام‌شده

- بررسی syntax تمام فایل‌های PHP
- ارسال فرم، مشاهده، خواندن و حذف درخواست در پنل
- ورود، خروج، رد CSRF نامعتبر و مسدودبودن مسیرهای خصوصی
- ذخیره محتوای سایت و انتشار/حذف پروژه با تصویر
- بارگذاری، اعمال فونت روی سایت و بازنشانی فونت
- تست مرورگر Chromium برای پنجره جزئیات، منوی موبایل و ورود پنل
- بررسی عرض‌های ۳۲۰، ۳۷۵، ۳۹۰، ۶۰۰، ۶۱۰، ۷۶۸، ۸۰۰، ۱۰۲۴، ۱۲۸۰ و ۱۴۴۰ پیکسل بدون اسکرول افقی
- حفظ یک بخش تصویری اصلی، معرفی خدمات با بازشدن یک توضیح در هر لحظه و امکان تغییر تصویر از پنل

### بررسی تکمیلی رابط کاربری

پیش‌نمایش اثر، بسته‌شدن با Escape و بازگشت اسکرول، مرور گالری موبایل و وضعیت دکمه‌ها در ابتدا/انتهای آن، بستن منوی موبایل، تبدیل شماره فارسی/عربی، شمارنده متن و ثبت/مشاهده درخواست در پنل با Chromium آزمایش شده‌اند. برای کاهش بزرگ‌نمایی ناخواسته در iOS، فیلدهای اصلی موبایل اندازه قلم ۱۶ پیکسل دارند.
