# نگاه مدیا | سورس وب‌سایت و پنل مدیریت

وب‌سایت فارسی و راست‌به‌چپ «کیان فناوران نگاه»، با PHP، CSS و JavaScript ساده، بدون دیتابیس یا فریم‌ورک. برای اجرای تولیدی روی IIS به Node.js احتیاج ندارد.

## امکانات فعلی

- هدر شناور شیشه‌ای و لوگوی واقعی نگاه، با امکان تغییر و بازنشانی لوگو از پنل
- طراحی روشن با پالت سبز، سرمه‌ای، زیتونی و کرم
- معرفی اصلی بدون نوشته‌های انگلیسی تزئینی
- نوار متحرک و مینیمال برندهای همکار با حداقل عرض ۱۰۰ پیکسل، توقف دستی و رعایت کاهش حرکت مرورگر
- سه اثر منتخب در صفحه اصلی؛ کارت‌های کامل و پلکانی در موبایل، بدون بریدگی افقی
- صفحه `/works.php` برای **همه کارها**، همراه فیلتر دسته‌بندی سمت سرور
- صفحه مستقل هر اثر در `/project.php?id=شناسه`، با لینک ثابت حتی پس از ویرایش عنوان
- توضیحات مستقل، کارفرما، سال، خدمات، کاور، گالری تصاویر و ویدیوی اختیاری برای هر پروژه
- نمایش بزرگ تصاویر گالری با کنترل قبلی/بعدی، کلیدهای جهت، Escape و توضیح تصویر
- فرم درخواست همکاری و مشاهده، خواندن و حذف پیام‌ها در پنل؛ بدون ایمیل یا پیامک خودکار
- بارگذاری فونت برای کل سایت، مدیریت خدمات، اطلاعات برند و برندهای همکار
- دسترسی اصلی به آثار، دسته‌بندی و فرم بدون وابستگی به JavaScript؛ JavaScript برای بهبود تعاملات است

آثار اولیه **مفهومی** هستند، نه ادعای انجام پروژه برای مشتری واقعی. توضیح هر اثر این موضوع را مشخص می‌کند. فقط شماره تماس و فرم، راه‌های ارتباطی عمومی سایت هستند.

## مسیرها

| مسیر | کاربرد |
| --- | --- |
| `/` | صفحه اصلی |
| `/works.php` | همه کارها |
| `/works.php?category=branding` | فیلتر دسته (branding، film، digital، campaign) |
| `/project.php?id=...` | صفحه اختصاصی یک اثر |
| `/admin.php` | پنل مدیریت |

نام کاربری اولیه `Mohusyn` است؛ رمز همان رمز اعلام‌شده در درخواست مالک است و در کد به‌صورت متن ساده ذخیره نشده. پس از ورود از **فونت و تنظیمات ← تغییر رمز عبور** رمز اولیه را عوض کنید.

## مدیریت لوگو و آثار

**لوگو:** پنل ← فونت و تنظیمات ← لوگوی سایت. فرمت PNG یا WebP شفاف پیشنهاد می‌شود؛ JPG نیز مجاز است. گزینه بازگشت، لوگوی اصلی ارسال‌شده توسط مالک را فعال می‌کند. نسخه اصلی در `assets/logo-original.png` و نسخه سبز مناسب زمینه روشن در `assets/brand-logo.webp` قرار دارد.

**پروژه:** پنل ← آثار و پروژه‌ها. برای هر پروژه عنوان، دسته، برچسب، توضیحات کامل و مشخصات اختیاری ثبت کنید. کاور جدا از گالری است. گالری هر پروژه مستقل ذخیره می‌شود. برای هر تصویر می‌توانید توضیح، ترتیب نمایش و حذف را تعیین کنید. تصاویر جدید به انتهای گالری اضافه می‌شوند. لینک پروژه از گزینه «مشاهده» در پنل در دسترس است.

**گالری:** هر تصویر حداکثر ۵ مگابایت؛ در هر ذخیره حداکثر ۸ تصویر جدید؛ هر پروژه حداکثر ۲۴ تصویر. فرمت‌های مجاز JPG/PNG/WebP هستند. عنوان و توضیحات به‌صورت متن امن نمایش داده می‌شوند، نه HTML اجرایی.

**ویدیو:** لینک مستقیم HTTPS با فرمت MP4 یا WebM از فضای رسانه خودتان. لینک صفحه یوتیوب یا آپارات نیست. ویدیو خودکار پخش نمی‌شود. دریافت یا تبدیل ویدیو در سرور این سایت انجام نمی‌شود.

**برندها:** پنل ← برندهای همکار. نام یا لوگوی برندهای واقعی را اضافه کنید. اگر برندی ثبت نشده باشد، بخش خالی نمایش داده نمی‌شود.

## نصب روی IIS

۱. PHP **8.1 یا جدیدتر** (ترجیحاً نسخه پشتیبانی‌شده 8.4/8.5) و قابلیت **CGI/FastCGI** را نصب کنید. مسیر `*.php` باید به `php-cgi.exe` نگاشت شود. قابلیت‌های استاندارد session، JSON، دریافت فایل و password hashing لازم‌اند.

۲. ریشه همین پروژه را به عنوان ریشه دامنه در IIS تنظیم کنید؛ نصب در زیرپوشه دامنه در این نسخه پیکربندی نشده است. `web.config` باید اعمال شود. URL Rewrite لازم نیست؛ آدرس صفحات PHP مستقیم است.

۳. به هویت Application Pool (مانند `IIS AppPool\NegahMedia`) فقط روی `data` و `uploads` مجوز **Modify** بدهید. روی بقیه فایل‌ها خواندن کافی است. پوشه session PHP نیز باید قابل نوشتن باشد. مجوز نوشتن عمومی Everyone ندهید.

۴. تنظیمات پیشنهادی `php.ini` برای گالری چندتصویری:

```ini
file_uploads = On
upload_max_filesize = 5M
post_max_size = 50M
max_file_uploads = 12
display_errors = Off
log_errors = On
session.use_strict_mode = 1
```

حد دریافت درخواست در `web.config` برابر ۵۲ مگابایت است. افزایش `post_max_size` ضروری است؛ مقدار قبلی ۶ مگابایت برای چند تصویر کافی نیست. محدودیت هر فایل در برنامه همچنان ۵ مگابایت است.

۵. MIME typeهای `.woff` → `font/woff`، `.woff2` → `font/woff2` و `.webp` → `image/webp` را اگر موجود نیستند در IIS اضافه کنید.

۶. HTTPS را فعال کنید. پس از ورود رمز اولیه را تغییر دهید. پیش از عمومی‌کردن سایت مسیرهای زیر باید پاسخ 404 داشته باشند:

```
/data/auth.json
/data/site.json
/.git/HEAD
/core.php
/views.php
/admin-projects.php
/tools/preview.mjs
```

قوانین منع دسترسی در `web.config` و منع اجرای اسکریپت در پوشه آپلود در `uploads/web.config` قرار دارند. صفحه‌های عمومی `index.php`، `works.php`، `project.php` و `admin.php` باید قابل دسترسی باشند.

۷. روی سرور نهایی یک پروژه با دو تصویر گالری اضافه کنید، لوگو را عوض کنید و یک فرم تماس بفرستید؛ صفحه پروژه و پیام را در پنل بررسی کنید.

**توجه:** جریان‌های PHP در محیط لینوکس و مرورگر Chromium آزمایش شده‌اند. IIS در این محیط موجود نیست؛ اعمال تنظیمات FastCGI، مجوزهای ویندوز و web.config باید روی سرور نهایی بررسی شود. Apache/Nginx به قواعد امنیتی معادل نیاز دارند و web.config را اعمال نمی‌کنند.

## اجرای محلی

با PHP بومی:

```sh
php -S 0.0.0.0:8080 router.php
```

سایت `http://localhost:8080/` و پنل `http://localhost:8080/admin.php` است. سرور توسعه برای تولید عمومی مناسب نیست.

در محیطی که PHP بومی نصب نیست، پیش‌نمایش اختیاری WebAssembly:

```sh
npm install --no-save @php-wasm/cli@3.1.58
node tools/preview.mjs
```

این ابزار تنها برای توسعه است و برای IIS لازم نیست. مسیر tools در IIS و router توسعه مسدود شده است.

بررسی بدون تغییر داده:

```sh
python3 tools/smoke.py http://localhost:8080
```

## داده و پشتیبان‌گیری

- `data/site.json`: اطلاعات سایت، لوگو، فونت، برندها، پروژه‌ها، شناسه‌های ثابت و گالری‌های مستقل
- `data/auth.json`: نام کاربری و هش bcrypt رمز
- `data/messages.json`: پیام‌ها؛ در اولین ارسال ایجاد می‌شود و خارج از Git است
- `data/attempts.json`: شمارنده تلاش‌های ورود؛ خارج از Git
- `uploads`: لوگو، فونت و رسانه‌های بارگذاری‌شده؛ خارج از Git

از `data` و `uploads` **با هم** و در محلی خصوصی پشتیبان بگیرید. هنگام انتشار نسخه جدید، داده‌های موجود سرور را با فایل‌های نمونه بازنویسی نکنید. پروژه‌های قدیمی بدون شناسه جدید نیز پشتیبانی می‌شوند و هنگام ذخیره، شناسه ثابت می‌گیرند.

حذف تصویر از گالری یا تعویض لوگو/کاور، فایل فیزیکی قبلی را خودکار حذف نمی‌کند تا فایل مشترک یا پشتیبان اشتباهاً از بین نرود. پاک‌سازی فایل‌های بدون استفاده را پس از پشتیبان‌گیری انجام دهید.

## به‌روزرسانی سورس با ZIP از پنل

در پنل مدیر، تب **به‌روزرسانی** اضافه شده است:

1. ZIP سورس جدید را انتخاب و «بررسی فایل ZIP» را بزنید. فهرست تغییرات، تعداد فایل‌ها و SHA-256 بسته نمایش داده می‌شود؛ در این مرحله کد سایت تغییر نمی‌کند.
2. پس از بررسی منبع بسته، گزینه اعتماد را انتخاب و **رمز فعلی مدیر** را وارد کنید. نصب تنها با نشست مدیر، CSRF معتبر و تأیید دوباره رمز انجام می‌شود.
3. پیش از جایگزینی، از کدهای قبلیِ تغییرکرده پشتیبان ZIP گرفته می‌شود. پس از نصب، پشتیبان از تاریخچه همان تب قابل دریافت است. بسته یکسان نصب نمی‌شود؛ بسته موقت را می‌توان لغو کرد و مهلت تأیید آن ۳۰ دقیقه است.

**برای سروری که هنوز این تب را ندارد:** این نسخه را فقط بار اول از طریق مدیریت فایل/FTP نصب کنید. ابتدا از کل سایت پشتیبان بگیرید، سپس فایل‌های کد و `assets` و `web.config` را جایگزین کنید؛ **`data` و `uploads` موجود را بازنویسی یا حذف نکنید**. پس از آن به‌روزرسانی نسخه‌های سازگار از داخل پنل در دسترس است. هدر عمومی این نسخه متن «نگاه مدیا» است؛ مدیریت لوگوی فوتر/پنل باقی مانده است.

### پیش‌نیاز و قالب بسته

- PHP با افزونه **ZipArchive / ZIP** و دسترسی نوشتن حساب Application Pool روی فایل‌های کد، `assets` و `data`. پس از پایان نصب می‌توانید مجوز نوشتن کد را دوباره محدود کنید؛ برای نصب بعدی باید موقتاً فعال شود. محافظت دسترسی وب به `data` و `tools` را حذف نکنید.
- حداکثر ZIP: **۵ مگابایت**؛ حداکثر مجموع بازشده: **۴۰ مگابایت**؛ هر فایل حداکثر **۸ مگابایت**؛ حداکثر **۵۰۰ ورودی**. محدودیت PHP/IIS باید اجازه آپلود ۵ مگابایت بدهد.
- بسته کامل سورس باید `negah-update.json` داشته باشد؛ ZIPهای قدیمی فاقد آن پذیرفته نمی‌شوند. برای ساخت بسته سازگار از `python3 tools/package.py` استفاده کنید. manifest با `format: negah-media-source`، `schema: 1` و جدول `files` شامل SHA-256 همه فایل‌ها تولید می‌شود. خود manifest در جدول هش نیست؛ یک پوشه اصلی مشترک یا فایل‌های مستقیم ریشه پشتیبانی می‌شود.
- مسیرهای ناامن، لینک‌ها، ورودی‌های تکراری، فایل خراب/هش نامطابق و PHP دارای خطای نحوی رد می‌شوند. هش **امضای ناشر نیست** و فقط یکپارچگی را بررسی می‌کند. آپدیت کد عملاً اجازه اجرای PHP می‌دهد؛ **فقط سورس مورد اعتماد خودتان را نصب کنید**. بررسی نحوی تضمین سازگاری یا نبود کد مخرب نیست.

### حفظ داده، پشتیبان و بازیابی

نصب پنل هرگز `data`، `uploads` یا `tools` را از بسته روی سرور بازنویسی نمی‌کند. تنظیمات، نام کاربری/رمز، پیام‌ها و رسانه‌ها حفظ می‌شوند. فایل‌های قدیمیِ حذف‌شده از نسخه جدید نیز خودکار پاک نمی‌شوند. فایل‌های موقت و پشتیبان در مسیر خصوصی `data/updates/` هستند؛ پشتیبان‌ها را دوره‌ای دریافت و به‌صورت دستی و با احتیاط پاک‌سازی کنید.

هنگام نصب، صفحات عمومی موقتاً پاسخ **503** می‌گیرند؛ پنل باز می‌ماند. اگر جایگزینی خطا بدهد، سیستم تلاش می‌کند همان تغییرات را برگرداند. اگر بازگردانی هم شکست بخورد، حالت نگهداری باقی می‌ماند و باید از مدیریت فایل هاست بازیابی کنید. پایان ناگهانی پردازش/قطع سرور نیز ممکن است نیاز به بازیابی دستی داشته باشد.

پشتیبان ZIP **فقط کدهای قبلیِ تغییرکرده** و `recovery.json` را دارد، نه کل سایت، داده‌ها یا آپلودها؛ این ZIP بسته آپدیت نیست و نباید در فرم آپدیت آپلود شود. برای بازیابی دستی، فایل‌های کد داخل آن را در مسیرهای قبلی جایگزین کنید و فایل‌هایی را که در `recovery.json` مقدار `before: null` دارند حذف کنید. پس از اطمینان از سلامت کد، فایل `data/update-maintenance.json` را حذف کنید تا سایت از حالت نگهداری خارج شود. قبل از هر انتشار، پشتیبان مستقل کاملِ کد و `data`/`uploads` داشته باشید. سازگاری نهایی با تنظیمات هاست IIS باید روی سرور خودتان بررسی شود.

## امنیت و بررسی‌ها

- کوکی HttpOnly و SameSite، محافظت CSRF، محدودسازی تلاش ورود و هش رمز
- قفل خواندن/نوشتن فایل JSON برای جلوگیری از تداخل درخواست‌ها
- اعتبارسنجی امضای تصاویر و فونت‌ها، نام تصادفی فایل، عدم پذیرش SVG/اسکریپت در آپلود
- متن و توضیح تصاویر escape می‌شوند؛ ویدیو تنها لینک مستقیم HTTPS است
- بررسی syntax تمام فایل‌های PHP و محافظت مسیرهای خصوصی
- بررسی صفحه اصلی، فهرست آثار و صفحه پروژه در عرض‌های ۳۲۰ تا ۱۴۴۰ پیکسل بدون اسکرول افقی
- آزمایش افزودن/ویرایش پروژه، ثبات لینک، بارگذاری کاور و چند تصویر، توضیح و مرتب‌سازی، حذف تصویر و استقلال گالری‌ها
- آزمایش نمایش بزرگ گالری، قبلی/بعدی، Escape و آزادشدن اسکرول
- آزمایش بارگذاری لوگو، نمایش در فوتر و پنل و بازنشانی؛ هدر عمومی فقط متن «نگاه مدیا» است

## دارایی‌ها

- لوگو توسط مالک ارسال شده؛ شکل اصلی حفظ شده و نسخه سبز برای زمینه روشن آماده شده است.
- فونت وزیرمتن با SIL Open Font License؛ مجوز در `assets/FONT-LICENSE.txt`.
- `vision-object.webp` رندر سه‌بعدی تولیدشده با هوش مصنوعی بر اساس نشان ارسالی مالک است: لوگوی سبز معلق با حفره دایره‌ای، جایگزین فرم چشم نواری قبلی. این تصویر پروژه مشتری نیست.
- طرح‌های اولیه آثار با HTML/CSS ساخته شده‌اند و نوشته‌های انگلیسی تزئینی‌شان حذف شده است.
- `hero-studio.webp` و `cinema-studio.webp` دارایی‌های نسخه قبلی هستند و در صفحه فعلی استفاده نمی‌شوند.
- عکس معماری: Unsplash، شناسه `photo-1622396481322-3b83d186701b`.
- از سایت‌های مرجع فقط در زبان طراحی الهام گرفته شده؛ لوگو یا محتوای آن‌ها کپی نشده است.

## راهنمای تصاویر و تنظیم اندازه لوگوهای همکار

در فرم پروژه، هینت کاور ۱۶۰۰ × ۱۲۰۰ و گالری افقی ۱۶۰۰ × ۱۲۰۰ / عمودی ۱۲۰۰ × ۱۶۰۰ پیکسل درج شده است؛ این‌ها پیشنهادند نه محدودیت آپلود.

حرکت نوار برندها آرام‌تر شده: یک دور دسکتاپ ۷۰ ثانیه و موبایل ۶۰ ثانیه؛ توقف با اشاره/دکمه و تنظیم کاهش حرکت دستگاه همچنان حفظ می‌شود. در تب «برندهای همکار»، کلاس اختصاصی هر برند به شکل `.brand-…` نمایش داده می‌شود؛ این کلاس با ویرایش نام یا حذف برندهای دیگر عوض نمی‌شود و روی هر دو نسخه نوار تکرارشونده یکسان است.

در همان تب، کادر **CSS سفارشی لوگوهای همکار** و نمونه تنظیم عرض/ارتفاع اضافه شده است. کلاس نمونه را با کلاس واقعی برند عوض کنید. کد در `data/site.json` ذخیره شده، با آپدیت سورس حفظ می‌شود و فقط پس از استایل‌های اصلی صفحه نخست اعمال می‌شود. برای بازنشانی، کادر را خالی و ذخیره کنید. CSS تنها برای مدیر مجاز است و نباید شامل تگ HTML باشد؛ فقط کد مورد اعتماد وارد کنید، زیرا CSS امکان تغییر ظاهر کل صفحه اصلی و بارگیری منابع خارجی را دارد.

## کارت اطلاعات کارفرما روی دسکتاپ

ارتفاع بیشینه لوگوهای همکار ۷۰ پیکسل و عرض بیشینه پیش‌فرض ۱۲۵ پیکسل است؛ CSS سفارشی پنل همچنان می‌تواند هر لوگو را جدا تنظیم کند. در نمایشگر حداقل ۱۰۲۴ پیکسل با ماوس دقیق و پشتیبانی هاور، نگه‌داشتن اشاره‌گر روی لوگو کارت اطلاعات را با حرکت نرم باز می‌کند. نوار تا زمانی که کارت باز است متوقف می‌شود. کارت بیرون از ناحیه برش نوار رندر می‌شود تا بریده نشود. روی موبایل، تبلت لمسی و نمایشگرهای کوچک غیرفعال است. فوکوس کیبورد هم کارت را باز می‌کند؛ Enter یا فلش پایین به لینک می‌رود و Escape کارت را می‌بندد. تنظیم کاهش حرکت دستگاه رعایت می‌شود.

توضیحات را در «برندهای همکار ← ویرایش برند ← اطلاعات کارفرما» وارد کنید. برای دکمه «دیدن کارهای این برند»، در فرم پروژه گزینه «برند مرتبط با پروژه» را انتخاب کنید. صفحه `/works.php?brand=brand-…` فقط آثار مرتبط با همان کلاس ثابت را نشان می‌دهد و تغییر دسته نیز فیلتر برند را نگه می‌دارد. پروژه‌های قدیمی بدون ارتباط مستقیم، در صورت یکسان‌بودن دقیق نام کارفرما با نام برند نیز نمایش داده می‌شوند؛ ارتباط مستقیم برای ثبات در تغییر نام توصیه می‌شود. برند بدون اثر، حالت خالی واقعی دارد و آثار ساختگی به آن نسبت داده نمی‌شود.

## CSS سفارشی کل سایت

تب مستقل «CSS سفارشی» در پنل، استایل دلخواه مدیر را در `data/site.json` با کلید `custom_css` ذخیره می‌کند. این کد بعد از استایل پیش‌فرض/فونت و CSS برندها در صفحه اصلی، فهرست آثار و تمام صفحات پروژه بارگذاری می‌شود؛ پنل و ورود عمداً از آن مستقل هستند تا CSS اشتباه دسترسی مدیریت را مختل نکند. نمونه کد تغییر رنگ، تیتر و فاصله‌ها در همان تب آمده است. سقف کد ۵۰ هزار بایت است و تگ HTML پذیرفته نمی‌شود؛ ذخیره نیازمند نشست مدیر و CSRF معتبر است. فقط CSS مورد اعتماد وارد کنید، زیرا CSS می‌تواند منابع خارجی بارگیری کند یا ظاهر صفحات را تغییر دهد. برای بازنشانی کادر را خالی و ذخیره کنید. این تنظیم مانند سایر داده‌های سایت با آپدیت سورس حفظ می‌شود.

تیتر اصلی در دسکتاپ کمی عریض‌تر شده: ستون متن فضای بیشتر، فاصله حروف کمتر فشرده و اندازه حداکثر ۶۴ پیکسل دارد؛ متن کشیده یا تبدیل هندسی نشده و اندازه موبایل بدون تغییر مانده است. نمایش تیتر در عرض‌های ۳۲۰ تا ۱۴۴۰ پیکسل بررسی شده است.

## تایپوگرافی دسکتاپ و تماس

اندازه و وزن تیترها مطابق درخواست مالک در عرض‌های ۱۲۰۰ پیکسل به بالا تنظیم شده است: تیتر اصلی ۷۰/۹۰۰، خدمات ۴۹/۹۰۰، منتخب آثار ۳۱/۸۰۰، درباره ۳۵/۸۰۰ و تماس ۳۶/۸۰۰. زیر این عرض اندازه‌ها سیال و در موبایل تیتر قابل شکستن است تا متن از صفحه بیرون نزند. نمایش در ۱۲ عرض از ۳۲۰ تا ۱۴۴۰ بررسی شده است. لینک تماس به‌جای نمایش درشت شماره، متن «تماس با ما» دارد و همچنان با `tel:` به شماره ذخیره‌شده در تنظیمات متصل است؛ بازشدن برنامه تماس به پشتیبانی دستگاه بستگی دارد. CSS سفارشی مدیر همچنان پس از این استایل‌ها اعمال می‌شود.

### محافظ ریسپانسیو تیتر

فایل `assets/responsive-guards.css` به‌صورت inline و پس از CSS سفارشی در صفحات عمومی بارگذاری می‌شود. اندازه تیتر اصلی زیر ۱۲۰۰ پیکسل محدود می‌شود و `white-space: nowrap` برای آن لغو می‌شود تا حتی در صورت وجود CSS سفارشیِ ۷۰ پیکسلی بدون media query، متن روی گوشی بریده نشود. از `!important` فقط برای این محدودیت‌های تیتر استفاده شده است؛ رنگ، وزن و سایر تغییرات CSS سفارشی همچنان قابل تنظیم‌اند. وزن نوشته «نگاه مدیا» در هدر ۷۰۰ است. حالت دارای CSS سفارشی متداخل در عرض‌های ۳۲۰ تا ۱۴۴۰ بررسی شده است.

### پالت آبی جدید

رنگ اصلی پیش‌فرض از سبز به `#152E64` تغییر کرده است. مکمل روشن `#8FAADC`، رنگ متن تأکیدی `#5679B6` (خواناتر روی زمینه روشن) و زمینه ملایم `#EDF2FB` انتخاب شده‌اند. پس‌زمینه‌ها، خطوط، دکمه‌ها، هاورها، پنل و نسخه پیش‌فرض نشان/تصویر اصلی با پالت آبی هماهنگ شده‌اند؛ فایل‌های اصلی لوگوی مالک و آپلودهای کاربر دست‌نخورده هستند. نام متغیر `--green` برای سازگاری CSSهای قبلی حفظ شده ولی اکنون مقدار آبی اصلی دارد. CSS سفارشی ذخیره‌شده مدیر همچنان مقدم است؛ اگر در آن رنگ سبز ثابت نوشته شده، باید از پنل اصلاح شود.

## هدر و معرفی وسط‌چین با الهام از مرجع ارسالی

بخش بالای صفحه با ساختار فارسی و راست‌به‌چپ بازطراحی شده است: نام نگاه مدیا در راست، منوی وسط و دکمه کپسولی شروع همکاری در چپ؛ هدر شیشه‌ای شناور باقی مانده است. تیتر دوخطی و دعوت به اقدام در مرکز، نشان معلق در زیر تیتر و دو کارت پیونددار کم‌حجم برای خدمات و آثار قرار دارند. از افراد، آمار یا مشتریان ساختگی مرجع استفاده نشده است. رنگ آبی و محتوای قابل ویرایش قبلی حفظ شده‌اند. کارت‌های کناری در موبایل مخفی‌اند؛ منوی جمع‌شونده تا عرض ۸۰۰ پیکسل فعال است. چیدمان، عدم برش متن و بازوبسته‌شدن منو در ۱۱ عرض از ۳۲۰ تا ۱۴۴۰ پیکسل بررسی شده است. CSS سفارشیِ قدیمی که چیدمان hero یا هدر را تغییر می‌دهد، ممکن است نیاز به بازبینی داشته باشد.

## بازطراحی سراسری جدید — استودیوی خلاق در طبیعت

**طراحی فعال فعلی** از مرجع منظره‌ای جدید الهام گرفته و جایگزین پالت آبی و هدر قبلی شده است. پس‌زمینه تمام‌عرض و سینماییِ استودیوی خلاق در طبیعت، آسمان گرم و فضای خلوت برای تیتر فارسی، هدر کوچک کپسولی شناور، دکمه‌های گرد و پالت کرم/زیتونی/سبز جنگلی دارد. تصویر `assets/creative-valley.webp` به‌صورت اختصاصی با هوش مصنوعی تولید و برای وب به حدود ۱۲۹ کیلوبایت بهینه شده؛ تصویر مفهومی است، نه عکس دفتر واقعی یا پروژه مشتری. بخش‌های برندها، آثار، خدمات، درباره و تماس و صفحات فهرست/جزئیات پروژه با همین زبان بصری هماهنگ‌اند. CSS این طراحی در `assets/landscape.css` قرار دارد و همچنان برای سازگاری با IIS به‌صورت inline خوانده می‌شود.

پس‌زمینه از **پنل ← فونت و تنظیمات ← تصویر اصلی سایت** قابل تعویض است. ورودی جدید با کلید `hero_background` در `data/site.json` ذخیره می‌شود؛ پیشنهاد تصویر افقی ۱۹۲۰ × ۱۰۸۰ با نیمه بالایی روشن و خلوت و سوژه‌های پایین/کناره‌هاست. حداکثر حجم ۵ مگابایت و فرمت‌های JPG، PNG و WebP حفظ شده است. گزینه بازگشت به پیش‌فرض تصویر طبیعت جدید را فعال می‌کند. کلید قدیمی `hero_image` خودکار حذف نمی‌شود ولی در طرح جدید استفاده نمی‌شود تا تصویر پرتره قدیمی به‌جای منظره بارگذاری نشود.

مدیریت پروژه‌ها، گالری‌ها، ارتباط برند/اثر، کارت هاور دسکتاپ، تماس تلفنی، فرم همکاری، CSS سفارشی و آپدیت ZIP باقی مانده‌اند؛ داده و آپلود کاربران با انتشار کد بازنویسی نمی‌شود. **CSS سفارشی قدیمی ممکن است پالت یا چیدمان قبلی را برگرداند**؛ در صورت تداخل، آن را از پنل بررسی یا پس از تهیه کپی خالی کنید. این نسخه CSS سفارشی کاربران را خودکار پاک نمی‌کند. پنل مدیریت از بازطراحی عمومی مستقل مانده است.

نمایش صفحه اصلی در ۱۱ عرض ۳۲۰ تا ۱۴۴۰، صفحات آثار و جزئیات در موبایل/دسکتاپ، منو و Escape، پیوندهای اصلی، کاهش حرکت، نمایش دکمه تماس و بارگذاری/بازنشانی پس‌زمینه از پنل آزمایش شده‌اند. نمایش واقعی روی هاست IIS نیازمند بررسی تنظیمات همان سرور است.

### پرداخت هدر شیشه‌ای و تصویر ۴K

هدر با زمینه نیمه‌شفاف چندلایه، blur/saturation پس‌زمینه، لبه روشن و سایه داخلی شبیه لیکوئید گلس شده است؛ در مرورگر بدون backdrop-filter زمینه خوانای جایگزین دارد. حرکت دکمه «کمی پایین‌تر» فقط ۴ پیکسل در چرخه ۳ ثانیه است و با تنظیم کاهش حرکت دستگاه قطع می‌شود. فاصله دو خط تیتر و فاصله نشان بالایی/توضیح/دکمه‌ها کمتر شده، همراه با حفظ محافظ ریسپانسیو.

تصویر با همان ترکیب‌بندی دوباره تولید و سه نسخه WebP باکیفیت ۱۲۸۰×۷۲۰، ۱۹۲۰×۱۰۸۰ و ۳۸۴۰×۲۱۶۰ ساخته شده است. **نسخه ۴K ارتقای اندازه از خروجی ۱۳۷۶×۷۶۸ تصویرساز با بازنمونه‌گیری Lanczos و شارپ‌سازی ملایم است، نه تولید بومی ۴K؛ افزایش ابعاد به‌تنهایی جزئیات واقعیِ ۴K ایجاد نمی‌کند.** فایل ۴K حدود ۸۰۰ کیلوبایت است. `srcset` و `sizes` با درنظرگرفتن برش object-fit:cover به مرورگر اجازه انتخاب نسخه متناسب با نمایشگر و تراکم پیکسلی را می‌دهند. تصاویر آپلودی مدیر به‌جای این مجموعه استفاده می‌شوند و بازنویسی نمی‌شوند.

### پس‌زمینه مرتبط با حوزه نگاه مدیا

پس‌زمینه منظره و خانه با تصویر مفهومیِ یک استودیوی تولید محتوا و طراحی جایگزین شد: دوربین سینمایی، نورپردازی، میز طراحی، قلم نوری و نمونه‌های گرافیکی. ترکیب‌بندی بالای تصویر روشن و خلوت، پالت گرم و هدر شیشه‌ای حفظ شده‌اند. این تصویر تولیدشده با هوش مصنوعی است و عکس محل واقعی شرکت نیست. نسخه‌های جدید `creative-studio.webp`، `creative-studio-hd.webp` و `creative-studio-4k.webp` هستند؛ نسخه ۳۸۴۰×۲۱۶۰ مانند قبل ارتقای اندازه از خروجی تصویرساز است، نه تولید بومی ۴K. برش موبایل برای دیده‌شدن دوربین تنظیم شده است. پس‌زمینه بخش درباره نیز با همین تصویر هماهنگ شده است. عکس آپلودی مدیر حفظ می‌شود؛ برای فعال‌کردن تصویر پیش‌فرض جدید در صورت وجود عکس سفارشی، از گزینه «بازگشت به تصویر پیش‌فرض» در تنظیمات پنل استفاده کنید.

## ظاهر فعال فعلی: بازگشت به نسخه آبی دو ستونه

به درخواست مالک، ظاهر عمومی به نسخه آبی پیش از بازطراحی‌های وسط‌چین/منظره برگشته است: هدر شناور، تیتر راست، تصویر داخل قاب در چپ، آثار و خدمات با چیدمان قبلی و بخش درباره سرمه‌ای. تصویر از کلید `hero_image` (آپلود قدیمی مدیر) خوانده می‌شود؛ `hero_background` مربوط به طرح تمام‌صفحه دیگر استفاده نمی‌شود ولی داده آن خودکار پاک نشده است. تصویر کنار تیتر از پنل قابل تعویض است و راهنمای ابعاد/پیش‌نمایش آن حفظ شده است. CMS، پروژه‌ها، برندها، CSS سفارشی و آپدیت ZIP حفظ شده‌اند؛ هیچ فایل داده یا آپلود کاربر برای این بازگشت بازنویسی نشده است. فایل‌های استایل/عکس استودیوی تمام‌صفحه در بسته جدید استفاده نمی‌شوند. CSS سفارشیِ مربوط به طرح‌های اخیر را در صورت تداخل از پنل بازبینی کنید. توضیحات بخش‌های تاریخی بالا درباره طرح منظره مربوط به نسخه‌های قبلی‌اند، نه ظاهر فعال.

## ظاهر تأییدشده فعلی: نسخه آبی وسط‌چین با دو کارت

طبق تصویر جدید مالک، بخش ابتدایی به نسخه آبیِ وسط‌چین بازگشته است: تیتر و دکمه‌ها بالا، تصویر اصلی زیر تیتر و دو کارت پیونددار در طرفین. هدر شناور، بخش‌های آثار/خدمات/درباره/تماس، داده‌های CMS و تصاویر آپلودی حفظ شده‌اند. این تغییر فقط چیدمان را از نسخه دو ستونه به نسخه وسط‌چین اصلاح می‌کند؛ توضیح تاریخی بخش قبل درباره «ظاهر فعال دو ستونه» دیگر وضعیت فعلی نیست. تصویر همچنان با `hero_image` از پنل مدیریت می‌شود و کارت‌های کناری در گوشی مخفی می‌شوند.

## معرفی فعال فعلی: متن و کارت‌های خدمات، بدون عکس

عکس از بخش معرفی حذف شده و تیتر، توضیح و دکمه‌ها محور اصلی هستند. سه کارت هویت بصری، تولید محتوا و طراحی وب با حرکت آرام ۵ پیکسلی در اطراف متن قرار دارند و به دسته مرتبط در فهرست آثار پیوند می‌دهند. در عرض ۱۰۰۰ پیکسل و پایین‌تر کارت‌ها به ردیفی ثابت زیر متن تبدیل می‌شوند؛ با تنظیم کاهش حرکت نیز انیمیشن قطع می‌شود. پالت آبی، هدر و بخش‌های پایین بدون تغییر مانده‌اند. تصویر آپلودی قدیمی حذف نشده، فقط در این طرح رندر نمی‌شود؛ وضعیت آن در پنل توضیح داده شده است. عدم برش و تداخل کارت‌ها با متن در ۱۲ عرض از ۳۲۰ تا ۱۴۴۰ پیکسل و پیوندهای هر سه کارت بررسی شده‌اند.

### جابه‌جایی عمودی کارت‌های معرفی با ماوس

در دسکتاپِ دارای ماوس (عرض بیشتر از ۱۰۰۰ پیکسل)، هر کارت خدمات را می‌توان با نگه‌داشتن دکمه چپ ماوس بالا و پایین کشید. موقعیت افقی ثابت است؛ حرکت در محدوده معرفی و بدون ورود به متن/کارت‌های دیگر محدود می‌شود. پس از عبور از آستانه ۵ پیکسل، حرکت به‌عنوان drag شناخته شده و کلیک پس از رهاکردن، لینک را باز نمی‌کند؛ کلیک عادی همچنان آثار همان دسته را باز می‌کند. Escape حرکت جاری را لغو می‌کند؛ Alt همراه کلید بالا/پایین برای جابه‌جایی با کیبورد پشتیبانی می‌شود. موقعیت فقط برای همان صفحه است و با تغییر اندازه یا بارگذاری مجدد بازنشانی می‌شود. موبایل/لمس درگیر drag نشده و اسکرول عادی حفظ می‌شود.
